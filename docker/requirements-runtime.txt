# rationale behind the torch / numpy / scikit-learn pins.
#
# torch is installed from the CPU wheel index in the Dockerfile
# (--index-url https://download.pytorch.org/whl/cpu), which resolves this pin to
# the 2.9.1+cpu build (~200 MB instead of the ~2.5 GB CUDA default).
